# About

## Hi, I'm Jakub Winkler

I'm a Magento Ninja Wizard Architect and open source enthusiast.

DJson was born from real-world e-commerce needs - creating dynamic JSON structures for product catalogs, API responses, and Schema.org structured data. What started as a solution for Magento projects has become a powerful library for any JSON generation needs.

## Why DJson?

Working extensively with e-commerce platforms, I needed a way to generate complex JSON that was:
- **Type-safe** - Prices must stay as numbers, not strings
- **Reusable** - Same template across different contexts
- **Maintainable** - Easy to read and update
- **Testable** - Can be validated and tested independently
